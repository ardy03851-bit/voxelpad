# Browser QA inventory

- Inspect the launcher at 1440×900, iPad landscape and portrait, and 375 px wide: original voxel portal artwork, readable hierarchy, visible start action, usable tap targets, and no sideways overflow.
- Open and dismiss each panel using its visible entry points. Exercise keyboard Escape, focus return, settings selectors, opacity range and profile persistence.
- Reject bad HTML or a server JAR; verify the exact uploaded ZIP and extracted HTML without a network transfer; test remember, reload, and remove.
- Launch the real client in a touch-capable browser, watch the loading overlay clear and the game canvas render. Inspect the imported client’s effective DPR and loaded graphics options. Exercise gameplay, the return warning and both exit choices.
- Test responsive controls and the install/fullscreen affordance. Examine Game Session, profile selection, file verification and empty/error states visually.
- Verify the public GitHub Pages origin serves JS modules correctly and opens the launcher without startup errors. Check cached reload while offline.
